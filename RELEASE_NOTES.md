# История изменений (Release Notes)

## Версия 0.5.1 (2026-09-27)

*Исправлены переносимость профиля браузера, оформление интерфейса и проверка Windows-сборки перед выпуском.*

### 🐛 Исправления ошибок

- Путь к профилю Yandex Browser определяется для текущего пользователя Windows.
- Пользовательский settings.json исключён из Git и чистой поставки; добавлен нейтральный settings.example.json.
- Сборка проверяет происхождение всех native-библиотек и прекращается при постороннем источнике.
- Полный комплект MSVC runtime берётся из PySide6 и проверяется по версии и SHA256.

### 🎨 Интерфейс

- Применена тема One Dark со шрифтом Tahoma и состояниями интерактивных элементов.
- Сохранена оригинальная иконка SearchDeck.

### 🛠 Улучшения

- Добавлены Windows version resource, SHA256 manifest и CI для lint, тестов и сборки.
- Перед post-build сохраняется проверенный COLLECT-00.toc и выполняется изолированный frozen GUI smoke.
- Установщик предлагает запуск приложения после установки; тихая установка его не запускает.
- Добавлены MIT-лицензия собственного кода, README RU/EN и актуальное описание доступа к исходникам.

## Версия 0.4.0 (2026-05-01)

*UI/release-релиз SearchDeck с нативным Windows-окном, масштабированием интерфейса и общим четырехуровневым релизным циклом.*

### ✨ Новые возможности
- Добавлен масштаб интерфейса в настройках: пользователь выбирает поправку `50%..150%`, а приложение сохраняет `ui_scale_delta_percent` в `settings.json`.
- Добавлен отдельный installer-flow `00_CrRel_setup.pyw` для сборки `SearchDeck_vX.Y.Z_Setup.exe` через Inno Setup без postinstall-запуска приложения.
- Добавлен `00_Move.pyw` для обновления portable-папки `portable-папку SearchDeck` из корневой сборки `SearchDeck/`.

### 🐛 Исправления ошибок
- Окно переведено с кастомного frameless-resize на нативную рамку Windows, поэтому изменение размера за края и углы снова работает стандартным способом ОС.
- Убрано дублирование заголовка и кнопки сворачивания: заголовок и системные кнопки теперь находятся только в нативной рамке окна.
- Исправлена формула ручной поправки масштаба: delta считается от `max(auto_percent, 100)` по стандартной модели масштабирования.

### 🛠 Улучшения
- Релизный цикл в `README.md` и `DEVELOPER.md` приведен к четырем уровням: подготовка, сборка, установщик+portable, dry-run публикации.
- `00_CrRel.pyw` закреплен как archive-flow и не запускается в третьем уровне без явной просьбы создать portable-архив.
- Добавлен `ruff` в dev-зависимости, `pytest` обновлен до `9.0.3` после OSV-проверки, расширено тестовое покрытие настроек масштаба, нативного окна и release-артефактов.

## Версия 0.3.0 (2026-04-09)

*Функциональный minor-релиз SearchDeck с динамическими вкладками, выбором профиля браузера и расширенным drag-and-drop каталога.*

### ✨ Новые возможности
- Вкладки стали динамическими: их можно добавлять, переименовывать и сохранять в `settings.json` вместе с активной вкладкой.
- Добавлен выбор номера профиля браузера через кнопку в верхней панели; последующие сценарии поиска сразу используют нужный профиль.
- В контекстное меню вкладки добавлена сортировка категорий, а в меню категории сохранена отдельная сортировка кнопок.
- Добавлен drag-and-drop reorder кнопок внутри категории и drag-and-drop reorder категорий внутри активной вкладки.

### 🐛 Исправления ошибок
- Исправлена ширина вкладок: теперь каждая вкладка рассчитывается по собственному тексту, а не по самой длинной подписи.
- Исправлена обратная совместимость `settings.json`: старые настройки мигрируются в динамическую модель вкладок и профиля браузера без потери каталога.
- Исправлено применение выбранного номера профиля к активации окна браузера и поисковому сценарию без перезапуска приложения.

### 🛠 Улучшения
- Добавлены визуальные линии вставки при перетаскивании кнопок и категорий.
- Контекстные меню перераспределены по сущностям: вкладка управляет категориями, категория управляет кнопками внутри себя.
- Расширено автотестовое покрытие GUI и сервисов для вкладок, профиля браузера, сортировки и drag-and-drop.

## Версия 0.2.1 (2026-03-17)

*Технический patch-релиз SearchDeck с исправлением всплывающего PowerShell и усилением release/build pipeline.*

### 🐛 Исправления ошибок
- Исправлено всплытие окна PowerShell перед выполнением сценария поиска в собранной версии приложения.
- Исправлен запуск PowerShell-процесса локатора браузера через скрытый Windows subprocess без появления консольного окна.

### 🛠 Улучшения
- Усилен `SpecCompiler.pyw`: перед новой сборкой автоматически удаляются старые build/dist-артефакты и старая папка приложения.
- Build pipeline переведен на `--clean --noconfirm` для чистой пересборки релизных артефактов.
- Уточнены release/build правила в `DEVELOPER.md`, `BUILD_TOOLS_GUIDE.md` и release-skill.

## Версия 0.2.0 (2026-03-17)

*Первый функционально насыщенный релиз SearchDeck с компактным frameless-интерфейсом, вкладками и расширенным workflow поиска в браузере.*

### ✨ Новые возможности
- Добавлен компактный frameless-интерфейс с аккордеонами категорий, контекстными меню и always-on-top режимом.
- Добавлены вкладки `СПб` и `Москва` с независимыми наборами категорий, кнопок и состоянием аккордеонов.
- Добавлены настройки задержек сценария: общий интервал между действиями и отдельная пауза после вставки.
- Добавлены drag-and-drop перенос кнопок между категориями и перенос через пункт `Перенести` в меню кнопки.
- Добавлены правый клик по кнопке для поиска в дублированной вкладке и `Ctrl+RightClick` для CRUD-меню.

### 🐛 Исправления ошибок
- Исправлен поиск окна Yandex Browser по нужному профилю с учетом `Local State`, заголовка окна и PowerShell decoding fallback.
- Исправлен нативный `SendInput` на Windows и добавлены недостающие scancode-сценарии для браузерного workflow.
- Исправлено всплытие лишнего контекстного меню после правого клика по кнопке.
- Исправлен Windows-resize frameless-окна за счет корректного `WS_THICKFRAME` и `WM_NCHITTEST`.

### 🛠 Улучшения
- Добавлены live-save геометрии окна и сохранение состояния аккордеонов в `settings.json`.
- Интерфейс приведен к единому визуальному стилю: вкладки, заголовки аккордеонов и единый шрифт `Calibri`.
- Расширено автотестовое покрытие GUI и сервисов для вкладок, настроек, drag-and-drop, build и browser workflow.

### 🛠 Улучшения
- Добавлены `DEVELOPER.md`, `.gitignore` и базовые release-артефакты.
- Runtime-пути переведены на dev/frozen-режим рядом с `.exe`.
- Добавлены тесты на версию, пути и build-related регрессии.
- Добавлены `requirements.txt`, `requirements-dev.txt`, `THIRD_PARTY_NOTICES.md` и `SOURCE_CODE_ACCESS.md` для первичного релиза.
