# Доступ к исходному коду

Исходники SearchDeck находятся в https://github.com/Frommer-droid/SearchDeck.

Репозиторий публичный. Исходный код и установщик доступны без авторизации.

Опубликованная версия 0.5.1 соответствует тегу [v0.5.1](https://github.com/Frommer-droid/SearchDeck/tree/v0.5.1).

Собственный код приложения распространяется по MIT. PySide6/Qt остаётся под собственными лицензиями. Приложение использует динамические Qt-библиотеки в _internal; пользователь может заменить их совместимыми сборками. Условия MIT не ограничивают права, предоставленные лицензиями Qt.

Оригинальные исходники Qt 6.10.2: https://code.qt.io/cgit/qt/qtbase.git/tag/?h=v6.10.2. Исходники Qt for Python: https://code.qt.io/cgit/pyside/pyside-setup.git/tag/?h=v6.10.2. Для модифицированных Qt-компонентов нужно самостоятельно соблюдать требования их лицензий; SearchDeck не вносит изменений в Qt/PySide6.
